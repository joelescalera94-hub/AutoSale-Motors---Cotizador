# Despliegue V2.6

Esta versión no requiere un nuevo parche SQL si ya ejecutaste los parches de V2.5 y seguridad anteriores.

1. Haz una copia del repositorio actual.
2. Reemplaza los archivos del repositorio del cotizador con los de este paquete V2.6.
3. Mantén tu `supabase-config.js` apuntando al mismo proyecto de Supabase.
4. Haz commit/push a GitHub Pages.
5. Espera la publicación y haz una recarga forzada (Ctrl+F5) una vez.
6. Prueba: contado, varias pestañas de vehículos, compartir por WhatsApp, guardado, clientes/seguimientos y Administración > Vehículos.

La Edge Function `admin-create-user` no cambió en esta versión.
